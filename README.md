# Carton Layer Fit

Compare axis-aligned uniform carton layouts in one layer.

Open `index.html` in a modern browser. Edit the sample inputs to update the result, then print or download it. Processing stays in the tab.

## Example

Base width (cm) = 120, Base length (cm) = 100, Carton width (cm) = 40, Carton length (cm) = 25. The first result is 12.
